## 💰 EJEMPLOS REALES

### Ejemplo 1: Recepción de Equipos (Retail)

```
DIAGNOSTICO:
"¿Cuánto cuesta hoy recepción manual?"
├─ 1 persona × 4 horas/día × $10/hora = $40/día
├─ × 22 días = $880/mes
└─ × 12 meses = $10.560/año PERDIDO

NUESTRA SOLUCIÓN:
"Automatizamos con RPA"
├─ Tiempo: Ahora 30 min (en lugar de 4 horas)
├─ Ahorro: 3.5 horas/día × $10 = $35/día
├─ Mensual: $35 × 22 = $770/mes RECUPERADO
└─ Anual: $9.240/año RECUPERADO

PYME PAGA:
"30% del ahorro"
├─ $770/mes × 30% = $231/mes
├─ O: Opción A: $2.772/año (mínimo)
├─ Opción B: $231/mes (más flexible)
└─ Opción C: 20% ahorro indefinido (partnership real)

RESULTADO:
├─ PYME recupera: $539/mes neto ($6.468/año)
└─ CONSULTORAVIRTUAL gana: $231/mes ($2.772/año)
    → Ambos ganamos
```

### Ejemplo 2: Decisiones de Compra (Logística)

```
DIAGNOSTICO:
"¿Cuánto cuesta NO tener datos para comprar?"
├─ Compras mal timed → Stock extra = $X/mes
├─ Proveedores no optimizados → Pagamos 15% más caro
├─ Sin predictivos → Oportunidades perdidas
└─ Dinero perdido: $2.000-5.000/mes

NUESTRA SOLUCIÓN:
"Predictivos + optimización compras"
├─ Datos históricos → Predicción de demanda
├─ Optimización proveedores → Mejor precio
├─ Decisiones data-driven → Menos errores
└─ Ahorro estimado: $1.500-3.000/mes

PYME PAGA:
"25% del ahorro"
├─ Si ahorro $2.000/mes → PYME paga $500/mes
├─ O estructura: $250/mes + 10% del ahorro extra
└─ Ejemplo: Enero ahorró $2.500 → Paga $625

RESULTADO:
├─ PYME recupera: $1.500/mes neto
└─ CONSULTORAVIRTUAL gana: $500/mes
    → Partnership real
```

## 📊 ESTRUCTURA DE VENTA (Sin pressure)

```
PASO 1: DIAGNÓSTICO (Gratis, 1 semana)
"¿Cuánto dinero pierdes realmente?"
├─ Mapeamos procesos (BPMN)
├─ Identificamos dinero perdido
└─ Entregamos: "Pierdes $X/mes en esto"

PASO 2: VISUALIZAR (Propuesta, 1 semana)
"¿Cómo recuperas ese dinero?"
├─ Mostramos opciones
├─ ROI de cada una
└─ Entregamos: "Opción A recupera 70%, cuesta esto"

PASO 3: DECIDIR (Tu decisión, sin pressure)
"¿Vamos?"
├─ Si SÍ: Ejecutamos
├─ Si NO: Sin problema, al menos sabés dónde pierdes dinero
└─ Entregamos: Contrato si decides

IMPORTANTE:
├─ Paso 1 es GRATIS (porque recuperar dinero es su idea, no nuestra)
├─ Paso 2 es bajo costo (propuesta, no implementación)
└─ Paso 3 es "Pagas de lo que ahorras" (risk transfer: TÚ decides)
```
