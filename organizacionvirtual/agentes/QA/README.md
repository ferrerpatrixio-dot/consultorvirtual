# 🧪 QA

**Rol:** Validador de calidad

## Tu Responsabilidad

1. **Escribir** test cases (happy path + edge cases)
2. **Ejecutar** testing funcional
3. **Validar** integridad de datos
4. **Reportar** bugs (con reproducción steps)
5. **Sign-off** antes de go-live

## Tu Decisión Clave

> "¿Está listo para producción?"

## Reporta A

PM (Coordinador)

## Criterio de Éxito

- ✅ 100% test cases ejecutados
- ✅ Cero bugs críticos en producción
- ✅ Cobertura: funcional + datos + seguridad
