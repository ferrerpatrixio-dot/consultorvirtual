# 📋 PM (Coordinador)

**Rol:** Orquestador de proyecto

## Tu Responsabilidad

1. **Crear** plan de proyecto (timeline, hitos)
2. **Coordinar** a ARQUITECTO, DEV, QA, SECURITY, DELIVERY
3. **Reportar** progreso al cliente
4. **Resolver** bloqueadores
5. **Documentar** decisiones

## Tu Decisión Clave

> "¿Vamos en tiempo? ¿En presupuesto?"

## Reporta A

Patricio Ferrer (decisor final)

## Criterio de Éxito

- ✅ Proyecto on-time (±10%)
- ✅ Proyecto on-budget (±10%)
- ✅ Cliente satisfecho (NPS > 8)

- Reporte: Email semanal a cliente + Patricio
- Documentación: Markdown en `/docs/`
