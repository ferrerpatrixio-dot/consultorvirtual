# 📖 GUÍA DE USO: DIPLOMADO POR ROL

**Objetivo:** Cada miembro del equipo sabe exactamente qué unidades del diplomado consultar para su rol  
**Formato:** Quick reference + Ejercicios prácticos  

---

## 🏗️ ARQUITECTO

### Tu pregunta típica:
**"¿Qué arquitectura IA es viable para esta PYME?"**

### Unidades diplomado que necesitas:

#### 🔴 OBLIGATORIA: Unidad 2 - Viabilidad de Proyectos IA

```
Qué aprendes:
├─ Framework: ¿Qué IA es viable para ESTA empresa?
├─ Criterios de selección (costo, complejidad, ROI)
├─ Análisis costo/beneficio IA
└─ Cómo rechazar proyectos no viables

Cómo lo usas:
├─ Cliente llega con idea
├─ Revisas U2 + diagnóstico del cliente
├─ Propones 2-3 arquitecturas alternativas
├─ Muestras viabilidad de cada una
└─ Recomiendas la que mejor fit

Pregunta para ti:
"¿Esta arquitectura es viable con el nivel de madurez que tiene el cliente?
¿O estamos sobre-diseñando?"
```

#### 🟡 RECOMENDADA: Unidad 4 - Análisis de Diagnóstico

```
Qué aprendes:
├─ Cómo medir estado actual
├─ Identificar cuellos de botella
├─ Qué datos son relevantes
└─ Cómo comunicar hallazgos

Cómo lo usas:
├─ Entiendes diagnóstico que hicimos en Etapa 1
├─ Propones arquitectura que NO amplifique problemas
├─ Explicas por qué cierta arquitectura es mejor que otra
└─ Evitas "soñar con humo"
```

#### 🟢 RECOMENDADA: Unidad 5 - Análisis Predictivo y Prescriptivo

```
Qué aprendes:
├─ Cómo funcionan modelos predictivos
├─ Cómo funcionan sistemas prescriptivos (IA decide)
├─ Qué datos necesitan
├─ Cómo validar que funcionan

Cómo lo usas:
├─ Si cliente quiere predicción → revisas U5
├─ Entiendes qué datos necesitas
├─ Propones arquitectura que soporte modelos
└─ Explicas riesgos y limitaciones
```

#### 🟢 COMPLEMENTARIA: Unidad 6 - Prototipo a Producción

```
Qué aprendes:
├─ Cómo llevar IA de prototipo a producción
├─ Qué testing es necesario
├─ Cómo monitorear en producción
└─ Cómo escalar

Cómo lo usas:
├─ Diseñas arquitectura pensando en ESCALABILIDAD
├─ No solo funciona ahora, funciona con 10x datos
├─ Propones infraestructura que aguante
└─ Evitas costosos rediseños post-launch
```

### Ejercicio para Arquitecto:

```
CASO: Cliente es retailer con 5 sucursales, 2K transacciones/día
Quiere: "Predicción de demanda + recomendaciones personalizadas"

PASOS:
1. Lee U2 (Viabilidad) → ¿Es viable? Revisa costo/beneficio
2. Lee U4 (Diagnóstico) → ¿Tiene datos limpios? ¿Procesos claros?
3. Lee U5 (Predictivo) → ¿Qué arquitectura de modelos necesita?
4. Lee U6 (Producción) → ¿Cómo escalamos de 5 a 50 sucursales?

Resultado: Propuesta arquitectónica en Etapa 2 (Visualizar)
```

## 💼 PRODUCT MANAGER

### Tu pregunta típica:
**"¿Qué oportunidades IA reales tiene este cliente? ¿Cuál priorizo?"**

### Unidades diplomado que necesitas:

#### 🔴 OBLIGATORIA: Unidad 1 - Crear Valor Empresarial con IA

```
Qué aprendes:
├─ Qué es "valor empresarial" de IA (no es usar IA por usar)
├─ Cómo medir ROI de IA
├─ Cómo evitar proyectos IA sin valor
└─ Cómo comunicar valor a cliente

Cómo lo usas:
├─ Cliente dice "quiero chatbot"
├─ Revisas U1 → ¿Qué valor genera chatbot?
├─ Si no hay valor claro → rechazas o pivoteas
├─ Si hay valor → lo cuantificas
└─ Esto te diferencia de competencia (que vende IA sin valor)
```

#### 🔴 OBLIGATORIA: Unidad 2 - Viabilidad de Proyectos IA

```
Qué aprendes:
├─ Cómo evaluar viabilidad de una oportunidad IA
├─ Criterios: costo, complejidad, ROI
├─ Cómo priorizar entre múltiples opciones
└─ Cómo comunicar por qué decimos SÍ o NO

Cómo lo usas:
├─ Después de diagnóstico, mapeas 5-10 oportunidades
├─ Usas U2 para evaluar cada una
├─ Escoges Top 3 por viabilidad + ROI
├─ Las presentas al cliente en Etapa 2 (Visualizar)
└─ Cliente entiende POR QUÉ esas opciones, no otras
```

#### 🟡 RECOMENDADA: Unidad 3 - Análisis Descriptivo con IA

```
Qué aprendes:
├─ Cómo describir estado actual con datos
├─ Qué métricas son relevantes
├─ Cómo comunicar "descripción" a cliente
└─ Cómo transformar descripción en oportunidades

Cómo lo usas:
├─ Tienes diagnóstico (Etapa 1)
├─ Usas U3 para describir visualmente a cliente
├─ "Mira, esto es lo que pasa en tu proceso"
├─ De descripción → "por eso te proponemos IA aquí"
└─ Cliente entiende problema + solución
```

#### 🟢 RECOMENDADA: Innovación U1 - Transformación Digital

```
Qué aprendes:
├─ Cómo transformar empresa (no solo meter IA)
├─ Impacto en cultura, roles, procesos
├─ Cómo vender transformación, no solo tecnología
└─ Cómo pensar roadmap a 2-3 años

Cómo lo usas:
├─ No solo preguntas "¿IA?" sino "¿Qué transformación necesita?"
├─ Propones roadmap de 3 años (no solo 3 meses)
├─ Cliente ve que ENTIENDES su transformación digital
└─ Esto diferencia PM experto de PM amateur
```

### Ejercicio para Product Manager:

```
CASO: Cliente es clínica con 50K pacientes/año, caos administrativo

PASOS:
1. Lee U1 (Valor) → ¿Qué IA genera valor? (ahorrar tiempo, dinero, calidad)
2. Lee U2 (Viabilidad) → ¿Qué opciones IA son viables? Evalúa 5-7
3. Lee U3 (Descriptivo) → Describe visualmente el estado actual
4. Lee Innov U1 (Transformación) → Piensa roadmap 2-3 años

Resultado: Roadmap de 3 oportunidades viables + presupuestadas
Presentas en Etapa 2: "Opción A: RPA (mes 1), Opción B: Predictivo (mes 3), Opción C: IA avanzada (año 2)"
```

## 🛠️ PROJECT MANAGER (YO)

### Tu pregunta típica:
**"¿Cómo implemento IA sin que se rompa la operación? ¿Cómo capacito equipo?"**

### Unidades diplomado que necesitas:

#### 🔴 OBLIGATORIA: Unidad 5 - Análisis Predictivo y Prescriptivo

```
Qué aprendes:
├─ Cómo funcionan modelos predictivos
├─ Cómo funcionan sistemas que deciden (prescriptivos)
├─ Qué validación necesitan
├─ Cómo explicar a equipo cliente

Cómo lo usas:
├─ Etapa 3 = Ejecutar soluciones
├─ Coordinamos DEV, QA, cliente
├─ Entienden cómo funcionan predictivos
├─ Podés explicar a cliente: "Esto es lo que va a pasar"
└─ Evitas sorpresas mid-proyecto
```

#### 🔴 OBLIGATORIA: Unidad 6 - Prototipo a Producción

```
Qué aprendes:
├─ Pasos: prototipo → validación → producción
├─ Qué testing es obligatorio
├─ Cómo monitorear en vivo
├─ Cómo ajustar si falla
└─ Cómo escalar

Cómo lo usas:
├─ Plan de ejecución fase por fase
├─ No saltamos testing (U6 dice por qué)
├─ Monitoreamos con métricas claras (U6)
├─ Si modelo predice mal → ajustamos (U6)
└─ Escalabilidad pensada desde inicio
```

#### 🟡 RECOMENDADA: Innovación U2 - Roles y Competencias en la era de IA

```
Qué aprendes:
├─ Cómo cambian roles en empresa con IA
├─ Qué capacitación necesita equipo
├─ Cómo vencer resistencia al cambio
└─ Cómo vender IA a equipos escépticos

Cómo lo usas:
├─ Planificas capacitación cliente
├─ No solo "aquí está la herramienta" sino "así es tu nuevo rol"
├─ Antícipas miedos (perder trabajo)
├─ Comunicás beneficios (menos trabajo aburrido, más análisis)
└─ Etapa 3-4 es mitad técnica, mitad capacitación
```

#### 🟢 RECOMENDADA: Transformación Digital - Ejes de Transformación

```
Qué aprendes:
├─ Estrategia de cambio
├─ Cómo implementar sin caos
├─ Cómo medir adopción
└─ Cómo sostener cambios

Cómo lo usas:
├─ Implementación de IA no es punto, es proceso
├─ Planificás cambios organizacionales en paralelo
├─ Monitoreás adoptación, no solo entrega técnica
└─ Cliente sustenta cambios post-proyecto
```

### Ejercicio para Project Manager:

```
CASO: Implementamos predicción de demanda en retailer (4 sucursales)

PASOS:
1. Lee U5 (Predictivo) → Entiendo cómo va a funcionar modelo
2. Lee U6 (Producción) → Planifique fases: prototipo → validación → producción
3. Lee Innov U2 (Roles) → Capacito gerentes de tienda en "leer predicción"
4. Lee Transformación → Monitoreo adoptación en vivo

Resultado: Plan de implementación con capacitación + monitoreo
Evito: Entregarles modelo y que nadie lo use
```

## 💰 COMERCIAL

### Tu pregunta típica:
**"¿Cómo convenzo al cliente? ¿Qué le prometo?"**

### Unidades diplomado que necesitas:

#### 🔴 OBLIGATORIA: Unidad 1 - Crear Valor Empresarial con IA

```
Qué aprendes:
├─ Qué vende: valor empresarial, no IA
├─ Cómo comunicar ROI
├─ Cómo evitar "vender humo"
└─ Cómo responder objeciones financieras

Cómo lo usas:
├─ Cliente: "¿Cuánto cuesta?"
├─ Tú: "Cuesta $X pero genera $Y de ROI"
├─ Cliente: "¿Esto me ayuda?"
├─ Tú: "Sí, específicamente en [métrica que entiende cliente]"
└─ Véndes valor, no features
```

#### 🟡 RECOMENDADA: Unidad 2 - Viabilidad de Proyectos IA

```
Qué aprendes:
├─ Qué es viable vender (no overselling)
├─ Cómo comunicar limitaciones
├─ Cómo explicar por qué ciertos proyectos No son viables
└─ Cómo vender alternativas

Cómo lo usas:
├─ Cliente quiere "IA que me haga prediciones perfectas"
├─ Lees U2 → Explicas realidad de precisión
├─ No prometes 99%, prometes 85% (realista)
├─ Véndes la verdad, no fantasía
└─ Cliente confía porque no mentiste
```

#### 🟢 RECOMENDADA: Caso Práctico - Recomendaciones Tienda Online

```
Qué aprendes:
├─ Ejemplo real de implementación IA en retail
├─ Problema → Solución → Resultado
├─ Cómo se vende cuando hay caso de éxito
└─ Números reales (no inventados)

Cómo lo usas:
├─ Cliente en retail → "Mira este caso similar"
├─ "Ellos tenían problema X, implementaron solución Y, resultado Z"
├─ Cliente: "Wow, eso podría funcionar para mí"
└─ Vendes con ejemplo, no con teoría
```

### Ejercicio para Comercial:

```
CASO: Cliente retail pequeño quiere "AI que venda más"

PASOS:
1. Lee U1 (Valor) → Entiendo que "vender más" = qué métrica? (tickets, monto, conversión)
2. Lee U2 (Viabilidad) → Evalúo qué es realmente viable para su madurez
3. Lee Caso práctico → Le muestro tienda online similar que lo hizo
4. Propuesta: "En lugar de 'IA genérica', aquí están 3 opciones viables con ROI claro"

Resultado: Cliente confía porque hablaste su lenguaje (dinero, resultados reales)
No le vendiste "chatbot", le vendiste "3% más en conversión = $X/mes"
```
