## ✅ ESTÁNDAR RECOMENDADO

### Verbos en presente
```
Usar segunda persona "tú" con verbo en presente:
✅ "tú eres" (NO "vos sos")
✅ "tú entiendes" (NO "vos entendés")
✅ "tú tienes" (NO "vos tenés")
```

### Lenguaje formal pero cercano
```
✅ "Tu operación"
✅ "Ves en qué estado está"
✅ "Tú decides"
❌ "Vos sos el que..."
❌ "Che, mirá esto"
```

### Cantidad
```
✅ "Muchos clientes"
✅ "Varios procesos"
❌ "Hartos clientes"
```

### Tiempo
```
✅ "De inmediato"
✅ "Rápidamente"
✅ "En el momento"
❌ "Al tiro"
❌ "Altiro"
```

### Trabajo/tareas
```
✅ "El trabajo que debemos hacer"
✅ "La tarea se completó"
✅ "El proyecto está en marcha"
❌ "La pega está lista"
```
