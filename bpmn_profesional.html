📋 Descripción del Proceso

Este diagrama BPMN profesional modela el flujo completo de recepción de equipos en la sucursal. El proceso se divide en 4 roles principales que actúan en secuencia:

🔀 Flujos Principales

✅ Camino Feliz (Proceso Normal)

1. Distribuidor llega → 2. Guardián valida entrada ✓ → 3. Bodeguero verifica todo ✓ → 4. Firma guía → 5. Ingresa a SAP ✓ → 6. FIN

⚠️ Camino de Discrepancias

Si se detecta error en cualquier validación: → Registra discrepancia → → Supervisor revisa → → ¿Resolvible? SÍ: Reintentar verificación | NO: Escalar a Gerencia

✅ Puntos de Control Críticos
# Punto de Control Responsable Decisión Acción SÍ Acción NO
1 Documentación válida Guardián ¿Válido? ✓ Autoriza bodega ✗ Rechaza entrada
2 Cantidad de cajas Bodeguero ¿= Guía? ✓ Continúa ✗ Discrepancia
3 Modelos de equipos Bodeguero ¿Correctos? ✓ Continúa ✗ Discrepancia
4 Condición física Bodeguero ¿Sin daño crítico? ✓ Firma guía ✗ Discrepancia
5 Pistolaje (SAP) Bodeguero ¿Físico = SAP? ✓ Ingresa serie ✗ Reintenta escaneo
6 Más cajas pendientes Bodeguero ¿Quedan cajas? ✓ Repite pistolaje ✗ Finaliza

✨ Características del Diagrama

  • ✓ Swimlanes claros - Separación por rol/departamento
  • ✓ Decisiones binarias - Cada compuerta tiene SÍ y NO
  • ✓ Loops integrados - Reintentos automáticos (pistolaje, más cajas)
  • ✓ Escaladas definidas - Supervisor → Gerencia para casos no resolubles

  • ✓ Sin ambigüedad - Todo error lleva a supervisor
  • ✓ Formato estándar - Compatible con herramientas BPMN
⚡ Regla de ORO

"NO SE PERMITE INGRESO MASIVO POR SISTEMA"

Cada serie DEBE ser ingresada manualmente mediante pistolaje/escaneo después de validación física. Esto garantiza que lo que está en SAP coincida exactamente con lo que hay físicamente en bodega, evitando pérdidas, robos o errores administrativos.
